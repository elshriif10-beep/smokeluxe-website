SMOKELUXE — COMPLETE GITHUB WEBSITE PACKAGE

This ZIP contains the entire website, not just a patch.
IMPORTANT: Do not upload the ZIP itself to GitHub. Extract it first.
Upload ALL files and folders from the extracted directory to the repository root.
The assets folder MUST contain all its files at assets/<filename>.

GitHub web interface: open your repository > Add file > Upload files.
On a computer, drag the entire extracted folder CONTENTS including assets folder.
Before committing, confirm GitHub shows index.html and assets/smokeluxe-new-hero.mp4 and assets/new-flavors.webp among the changes.
Commit changes; then wait for Netlify Deploys > Published.
Check https://smokeluxe.ae/assets/smokeluxe-new-hero.mp4
Check https://smokeluxe.ae/assets/new-flavors.webp
Then reload https://smokeluxe.ae/
